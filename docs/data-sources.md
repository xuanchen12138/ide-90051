# Sources, attribution and licences

- Victorian Department of Transport and Planning: [GTFS Schedule](https://opendata.transport.vic.gov.au/dataset/gtfs-schedule) and [GTFS-Realtime](https://opendata.transport.vic.gov.au/dataset/gtfs-realtime). These portal datasets specify [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The application displays Transport Victoria attribution. Derived artefacts select Route 58 geometry, clip a local display segment and normalize realtime records. The original source is not modified.
- [GTFS Schedule specification](https://gtfs.org/documentation/schedule/reference/) and [GTFS-Realtime reference](https://gtfs.org/documentation/realtime/reference/) define parsing and selector/time semantics. The project does not assume passenger numbers are data identifiers.
- [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) supply the cached local geographic context: roads, building footprints, bridges, water and parks. The data is licensed under the [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Retain the on-map attribution and licence link when displaying or redistributing the map; the derived geographic data remains available under ODbL. Extraction provenance and coverage are documented in [basemap-data.md](basemap-data.md).
- [Google Maps JavaScript API](https://developers.google.com/maps/documentation/javascript) supplies the optional configured basemap, subject to Google's terms and billing. Preserve Google attribution; use an appropriately restricted [browser key](https://developers.google.com/maps/api-security-best-practices). No Google imagery or models are downloaded, scraped or repackaged.
- [Google map styling](https://developers.google.com/maps/documentation/javascript/cloud-customization/map-styles) supports an optional vector map ID and monochrome cloud styling. Without a map ID the application uses the configured JavaScript style on a 2D map.

The official GTFS dataset page documents `KeyID` for authentication. Some downloadable OpenAPI examples show older generic subscription-header names; this implementation follows the guide and current dataset notes and was tested with `KeyID`. The initial standalone urllib attempt returned 403; subsequent actual adapter requests obtained and decoded all three feeds. No cause is asserted for that initial failure.

The source city image is only a style reference; it is not a geographic source or asset library. The keyless map combines cached OpenStreetMap geography with the separately sourced official GTFS lines/points and the explicitly conceptual flood mask. Street and building coordinates come from the source extract, not hand-drawn approximations or Google imagery. Rendering uses the local GeoJSON endpoint rather than online map tiles. Coverage is local to Southbank; the full Route 58 view outside the extract remains a GTFS route overview. OpenStreetMap is community-maintained geographic data, not a survey or a live road-closure feed.

Rainfall context, alternative-route routing, flood prediction, 3D city models, Google Earth imagery, production control and multi-site analysis are not part of this implementation.
